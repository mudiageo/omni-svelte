## Description

This fixes an issue where schemas with circular relationships caused the dynamic model generation to crash and default the relationship target to `'unknown'`.

The solution converts the `static relationships` property on the dynamic model into a static lazy getter. This safely defers the execution of relationship thunks (e.g. `() => priceReportSchema`) until the relationships are accessed, by which point all circular imports have been fully initialized.
